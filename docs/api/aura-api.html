AURA Care-Chain API (1.0.0)

Download OpenAPI specification:

License: Uso acadêmico — FIAP 2026

API REST do AURA Care-Chain — assistente de saúde domiciliar voice-first para idosos com Parkinson, com cadeia logística de segurança da casa.

Consumida por três clientes: app Flutter (Android/iOS/Web), app React Native e painel administrativo Angular.

Regras de ouro: nunca prescreve nem diagnostica, o escore é sempre explicável (fatores + pesos) e nenhum dado de saúde é gravado sem consentimento LGPD.
